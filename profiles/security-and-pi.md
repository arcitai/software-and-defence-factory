# Specialistprofiler

**Codex Security** er første foreslåede specialistspor: repository/diff-scan, validering af fund, remediation og efterprøvning på den ændrede revision. Brug de Security-skills og Daybreak-adgange, som findes på den konkrete produktflade. At en model er tilgængelig i Gustav's Codex-konto beviser ikke adgang via en kundes API eller i en ubemandet worker. Profilen giver derfor manuel overdragelse, indtil den konkrete integration er afprøvet. Pluginfiler er ikke kopieret eller viderelicenseret her.

**Pi custom** er et valgfrit udvidelsespunkt. Det kan være attraktivt til egen provider og meget lille runtime, men det er ikke vores nemmeste standardsetup. Basis fil-/shell-værktøjer skal suppleres med konkrete web/browser/computer-funktioner, sandbox, auth, stop og overvågning. Vælg navngivne, vedligeholdte extensions efter den konkrete opgaves behov og afprøv dem; installér ikke en tilfældig stor pakke for at ligne Cursor. Repoet indeholder hverken en Pi-launcher eller påstand om native desktopværktøjer i Pi.

Alternative modeller vurderes på samme fixture, rubric og datascope. Hypotetiske fremtidige modelnavne er ikke lagt ind som fungerende integrationer.

Kilder: [Pi](https://github.com/earendil-works/pi), [OpenAI Defense Factory](https://openai.com/the-defense-factory/).
