Én factory. Ét dashboard.

En testbar pakke på Machinist til software, security og Defence. Kør den på en VPS eller egen maskine, og behold dit repo, din agent, model og apphosting.

Genbrug Machinist. Saml Arcitai-arbejdsgangene ovenpå. Prøv først npm run factory -- demo: isoleret ændring → tests → separat review → din godkendelse. Derefter forbindes egen app og model. Quickstart og VPS.

Tre arbejdsforløb på samme platform

Software

Opgave → vertical slice → tests og review → patch til din PR. Én lille adfærd fra ende til ende, før næste udvidelse.

Security

Undersøgelse → valideret fund → rettelse og bevis. Specialist og kontroller vælges efter ændringens risiko.

Defence og drift

Manuel evidens → privat triage-udkast → review og eventuel softwareopgave. Kan også dække software bygget andetsteds.

Fælles jobstyring, historik og målinger. Egne rettigheder og private beviser pr. forløb. Første incidentprofil undersøger og foreslår; en 500-fejl er ikke automatisk et sikkerhedsproblem.

Hvad bruger vi til hvad?

v0.2-testudgave — konkrete standarder, åbne tilvalg
DelValg og ansvar
Motor og dashboardMachinist: kø, workflows, worker, godkendelser og historik. Genbrug GUI’en først.
ArbejdsgangeArcitais seks skills, projektkontekst, reviewregler og beviser. Risiko vurderes i den konkrete app.
Agent og modelCodex og Pi er installeret i jobimaget. Egen command/image er muligt. Modeladgang og kvalitet skal afprøves i piloten.
Agentens computerDocker-jobs på Mac eller Linux/VPS. Browser kræver et tilpasset image; ingen GPU nødvendig med ekstern inference.
GitHub og ActionsIssues, PR’er og almindelig CI/CD. Langvarigt agentarbejde kører på worker; appens eksisterende deployment bevares.
Dokumenteret værdiForsøg, checks, review og varighed gemmes. Pris, modelusage og mennesketid er endnu ukendt; syntetiske tests er ikke kundeværdi.

VPS’en fortsætter, når laptoppen lukkes. Lokal drift kræver en vågen maskine. Cloudflare Sandbox er et muligt senere tilvalg med betaling; ingen obligatorisk platformsubscription eller Archon.

Risiko er relativ — og skal kunne forklares

Hvad kan gå galt, hvem rammes, og kan vi opdage og gendanne det? Det afgør tests, specialistreview og releasekrav. En lille ændring i adgangskontrol kan kræve mere end en stor tekstrettelse. Ukendt risiko bliver ikke automatisk lav.

En score eller lavrisikolabel giver ikke i sig selv lov til merge, deploy eller rollback. Videoens tidskoder, originalartiklen og vores regel.

Næste pilot i vertical slices

1. Test installationenKør demoen. Miljø, reviewgate, fejl, stop og genstart er kvalificeret lokalt uden modelkald.

2. Forbind én rigtig appVælg model og appchecks. Lever én lille ændring som patch og opret PR gennem appens normale flow.

3. Afprøv VPSKør samme pakke som systemd-service med privat SSH-adgang. Automatisk issue-polling er en senere udvidelse.

Defence: manuel evidens-triage er med. En live telemetry-connector og verificeret recovery er endnu ikke implementeret.

Status: CLI, Machinist-dashboard, Docker-isolation og manuelle workflows er klar til pilotafprøvning. Rigtige modelkald, Linux-VPS og production connectors er ikke kvalificeret. Ingen automatisk PR, merge, deployment eller recovery.
