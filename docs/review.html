Én factory. Ét dashboard.

En færdigsamlet pakke på Machinist til software, security og Defense. Kør den på en VPS eller egen maskine, og behold dit repo, din agent, model og apphosting.

Genbrug Machinist. Saml Arcitai-arbejdsgangene ovenpå. Start pakken → forbind repo og model → afprøv miljøet → send første issue. Standardvalg følger med; tilpasning er mulig. Den samlede pakke skal stadig bygges.

Tre arbejdsforløb på samme platform

Software

Issue → vertical slices → tests og review → verificeret PR. Én lille adfærd fra ende til ende, før næste udvidelse.

Security

Undersøgelse → valideret fund → rettelse og bevis. Specialist og kontroller vælges efter ændringens risiko.

Defense og drift

Alarm → diagnose → forslag eller ny softwareopgave → opfølgning. Kan også dække software bygget andetsteds.

Fælles jobstyring, historik og målinger. Egne rettigheder og private beviser pr. forløb. Første incidentprofil undersøger og foreslår; en 500-fejl er ikke automatisk et sikkerhedsproblem.

Risiko er relativ — og skal kunne forklares

Hvad kan gå galt, hvem rammes, og kan vi opdage og gendanne det? Det afgør tests, specialistreview og releasekrav. En lille ændring i adgangskontrol kan kræve mere end en stor tekstrettelse. Ukendt risiko bliver ikke automatisk lav.

En score eller lavrisikolabel giver ikke i sig selv lov til merge, deploy eller rollback. Videoens tidskoder, originalartiklen og vores regel.

Byg og bevis i vertical slices

1. Repo → fungerende miljøVis et rigtigt appcheck i Machinist. Afprøv isolation, relevant testfejl, stop og genstart.

2. Issue → verificeret PRKør én reel ændring med separat review, korrekt revision og målte resultater.

3. Drift uden åben laptopForbind issue-polling til workflowet. Afprøv dubletter, mistet worker og vedvarende budget.

Derefter: ét driftsignal → read-only incidentundersøgelse → privat sag → forslag eller softwareissue. Samme motor og dashboard.

Status: metodekit og prototype findes. Machinist er bygget og testet lokalt med syntetiske processer. Arcitai-installation, rigtig model-/apppilot og incidentconnector er endnu ikke færdige. Owains Google Cloud-demo er separat kode, ikke en indbygget Machinist-connector.
